# sql_project_data_cleaning
SQL Data Cleaning Project
About the Project

This project focuses on cleaning raw data using SQL. The purpose of this project is to improve data quality and prepare the dataset for further analysis.

Objectives
Remove duplicate records.
Handle missing and NULL values.
Standardize data formats.
Identify and correct inconsistent data.
Prepare clean data for analysis.
Tools Used
SQL
MySQL

Checked data consistency.
Validated the cleaned dataset.
